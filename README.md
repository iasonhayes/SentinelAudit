## Features 
- Collects Linuz system information
- Audits running processes
- Checks file permissions 
- Enables and verifies the UFW firewall
- Calculates a security score
- Generates timestamped security reports 
- Displays startup and completion dialogs

## Requirements 
- Ubuntu or another Debian-based Linux system
- Bash
- Zenity 
- UFM

## Usage
chmod +x assessment_tool.sh
./assessment_tool.sh
